# Decentralized Marketplace for Used Goods
A secure and decentralized marketplace powered by Stacks blockchain for buying and selling used goods with NFT-backed listings and escrow protection.

## 🚀 Features

- NFT-backed listings
- Secure escrow system
- Automated payment processing
- Listing management
- Ownership verification

## 🔧 Technical Stack

- Clarity Smart Contracts
- Stacks Blockchain
- React Frontend
- Clarinet Testing Framework

## 📦 Installation

```bash
clarinet new decentralized-marketplace
```

## 🧪 Testing

```bash
clarinet test
```

## 🔐 Security Features

- Input validation
- Access control checks
- Escrow protection
- NFT ownership verification

## 💻 UI Components

- Product listing dashboard
- Item detail view
- Escrow status tracker
- Transaction history
- NFT ownership viewer
